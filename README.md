# RESCUE-SHADOW

## Disaster Search and Rescue Support System

### Problem
During disasters, rescue teams may struggle to organize
missing-person reports and track search progress.

### Solution
Rescue-Shadow helps organize reports and monitor rescue status.

### Features
- Add missing-person reports
- View registered reports
- Update rescue status
- Store reports locally

### Technology
- Python
- JSON
- Visual Studio Code
- GitHub

### Future Improvements
- Rescue priority assessment
- Search history tracking
- Interactive disaster dashboard
- Offline data synchronization

## Disclaimer
This is an educational prototype, not an official emergency
response system.
